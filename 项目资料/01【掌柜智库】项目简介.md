# 项目简介

> 本文档为掌柜智库的全景概览，涵盖项目概述、系统架构、第三方中间件与核心技术栈介绍。 

## 第1章 项目概述

### 1.1 项目定位与目标

**项目定位：**

掌柜智库是一个企业级智能知识库系统，基于 **RAG（检索增强生成）** 技术，旨在为垂直领域（如电子产品手册、维修指南、技术文档等）提供精准、智能的知识检索与问答服务。

**核心目标：**

- 将非结构化文档（PDF、Markdown）转化为可检索的结构化知识
- 通过多路召回策略提升检索准确率
- 提供流畅的流式问答交互体验

### 1.2 核心模块

**数据处理流水线 (Data Pipeline)**：支持 PDF、Markdown 等多格式文档导入，执行文档结构化解析、智能切片、元数据提取及向量化存储的全链路预处理。（为智能客服提供数据支撑）

<img src="images/01-知识库文件导入.png" alt="01-知识库文件导入" />

**智能检索系统 (Retrieval System)**：集成混合检索、假设性问题生成 、联网搜索及结果重排序等高级策略，确保回答的准确性与时效性。

<img src="images/01-知识库查询.png" alt="01-知识库查询"  />

### 1.3 核心功能特性

| 功能模块         | 描述                                               |
| ---------------- | -------------------------------------------------- |
| **文档智能导入** | 支持 PDF/Markdown 文件上传，自动解析、切分、向量化 |
| **混合向量检索** | 稠密向量 + 稀疏向量混合检索                        |
| **多路召回融合** | 向量检索 + HyDE + Web 搜索                         |
| **智能重排序**   | Reranker 模型重排序，断崖检测动态截断              |
| **流式问答**     | SSE 实时推送，逐字输出答案                         |
| **会话历史管理** | MongoDB 存储对话历史，支持上下文连续对话           |

### 1.4 适用场景

- **产品手册问答**：电子产品使用说明、维修手册等
- **技术文档检索**：API 文档、开发指南、FAQ 等
- **企业知识库**：内部制度、操作规范、培训资料等
- **售后客服支持**：产品故障排查、使用指导等

### 2.2 核心模块说明

| 模块             | 职责                       | 技术实现                 |
| ---------------- | -------------------------- | ------------------------ |
| **API 层**       | HTTP 接口暴露、请求路由    | FastAPI + Uvicorn        |
| **Processor 层** | 业务流程编排、节点调度     | LangGraph                |
| **Utils 层**     | 工具函数封装、外部服务调用 | Python 模块              |
| **数据层**       | 数据持久化、检索           | Milvus / MongoDB / MinIO |

### 2.3 技术栈选型

| 类别           | 技术选型                          | 说明                                                         |
| -------------- | --------------------------------- | ------------------------------------------------------------ |
| **后端框架**   | FastAPI + Uvicorn                 | 异步高性能 HTTP 服务，自动生成接口文档，高并发适配AI推理接口场景 |
| **工作流引擎** | LangGraph                         | 有状态图编排框架，支持多轮工具调用、分支判断、记忆持久化，搭建智能体流程 |
| **大语言模型** | qwen-flash / qwen3-vl-flash       | 通义千问轻量化高速文本大模型 + 多模态视觉大模型，支持图文问答、长文本生成 |
| **向量嵌入**   | BGE-M3 / text-embedding-v4        | 双嵌入模型；BGE-M3同时输出稠密+稀疏向量，支持混合检索；text-embedding-v4通用高精度语义向量化 |
| **重排序模型** | BGE-Reranker-Large / qwen3-rerank | 检索后精细打分重排，过滤语义无关文档，大幅提升知识库问答精准度 |
| **向量数据库** | Milvus                            | 高性能分布式向量检索引擎，海量文档向量存储、近似相似度快速召回，适配RAG检索场景 |
| **文档数据库** | MongoDB                           | 非结构化文档数据库，灵活拓展字段，存储对话历史               |
| **对象存储**   | MinIO                             | 兼容S3协议轻量对象存储，统一管理上传PDF、图片、附件等二进制文件资源 |
| **PDF解析**    | MinerU                            | 专业文档解析工具，精准还原PDF图文、表格、公式结构，输出干净可检索Markdown文本 |
| **前端**       | HTML + CSS + JS                   | 无前端框架原生开发，轻量化、低部署成本，实现对话交互、文件上传、结果展示页面 |
